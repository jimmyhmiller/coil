# The runtime corpus: large, self-checking programs, one per area of the language.
# Run by `scripts/oracle.py corpus <lane>`; see that file for the options.
# FAST runs every program on arm64, LLVM and the interpreter, the `safety` ones
# under coil.safety and the `meta-interp` one with the interpreted metaprogram
# engine. COMPREHENSIVE runs safety and meta-interp over all of them (`--all`).
types_traits.coil        meta-interp
sums_match.coil
ownership.coil           safety
memory.coil
# A const that allocates at compile time cannot be built under coil.safety: the
# safety transform's process-wide debug allocator registers an atexit handler, and
# compile-time code that calls atexit crashes the compiler or fails to produce a
# value. Remove the marker when that is fixed.
comptime.coil            safety-fails="cannot be materialized as a compile-time literal"
ffi_abi.coil
numerics.coil            interp-refused="does not support integers wider than 64 bits" x64-refused="does not support integers wider than 64 bits"
control_collections.coil safety -- alpha beta gamma
