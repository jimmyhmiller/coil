# Serde for Coil — design & implementation notes

Status: **IMPLEMENTED** (v2 — options, DOM, post-hoc sum derive included). A serialization framework in the spirit of Rust's
serde: data structures and data formats are decoupled through a small data
model, and per-type code is generated by derive macros — as a pure library, no
compiler support, exactly like `coil.derive`'s `Eq`/`Hash`.

> **Current derive spelling:** the earlier `derive-serde`,
> `derive-serde-sum`, `derive-serialize`, and `derive-deserialize` entry points
> described below have been retired. Use `(derive Serialize Deserialize T)`;
> configured derives use option-bearing trait specs, for example
> `(derive (Serialize (rename-all :camelCase)) (Deserialize (rename-all
> :camelCase)) T)`. `defsum-serde` remains because it defines a type as well as
> its codec implementations.

## What exists today (the survey)

- **`coil.json`** (`src/stdlib/json.coil`) — a fast, validating, zero-copy JSON
  *parser*. Output is a flat preorder token tape (`Doc`/`Token`): containers record
  direct child counts, strings/numbers are byte ranges into the caller's input.
  Random access over the tape is already provided (`object-get`, `array-nth`,
  `json-next-index`). There is **no writer/serializer, no unescaper, no number
  parser, and no typed decoding** — callers hand-walk tokens.
- **`src/examples/json.coil`** — a DOM-style `Json` sum (example only, ints-only,
  no escapes). Not stdlib.
- **`coil.derive`** (`src/stdlib/derive.coil`) — the established pattern this design
  extends: macros reflect on a type (`code-field-count/name/kind/type`) and emit a
  trait impl. Its hard rules carry over: unsupported shapes are a **compile-time
  hard error with a clear message**, never silently wrong.
- **Reflection** — structs *and* sums: `code-variant-sum/-count/-name/-fields`, and
  generic-instantiation reflection (`code-field-type (Pair i64 (ptr u8)) 1` →
  `(ptr u8)`), so derives see concrete field types through generics.
- **Traits** — bounds on generic impls (`(impl [(T Eq)] Eq (Box T) …)`),
  specialization, inherent methods, and first-class **`(dyn Trait)`** two-word
  trait objects (methods must take `(self (ptr Self))`, no `Self` elsewhere).
- **IO** — `Writer` capability (`coil.io`): fd, buffered, null, and `FixBuf`
  sinks; `coil.fmt` printers; `StrBuf` in `coil.str`.
- **Errors** — `Result`/`Option` in the prelude, `try!`/`try` macros (`coil.try`).
- **Allocation** — the `(dyn Allocator)` threading convention.

## Architecture: three parties, N + M

```
 your types                the data model                 formats
┌───────────┐   Serialize  ┌────────────────┐  impls of  ┌──────────────┐
│ defstruct │ ───────────► │   Serializer   │ ◄───────── │ JSON writer  │
│ defsum    │              │  Deserializer  │            │ JSON tape    │
│ ArrayList │ ◄─────────── │   (traits)     │            │ sexp, msgpack│
└───────────┘  Deserialize └────────────────┘            └──────────────┘
      ▲
      │  (derive-serde T …) — reflection-generated impls, coil.derive-style
```

- **`Serialize` / `Deserialize`** — implemented per *type* (mostly by derive).
- **`Serializer` / `Deserializer`** — implemented per *format*. These two are the
  **dyn traits**: `Serialize::ser` takes a `(dyn Serializer)`, so one derived impl
  works with every format (N types + M formats, not N×M). This is the Coil answer
  to serde's generic `fn serialize<S: Serializer>` — Coil trait methods can't carry
  their own type parameters, but `(dyn Trait)` gives the same decoupling with one
  vtable call per data-model event.
- **Extensibility hook for free**: derive recurses into fields by emitting `(ser
  (field x f) s)` — trait dispatch picks up a *hand-written* impl for a field's
  type exactly as it picks up a derived one, the same way `derive-eq` recurses
  through `=`.

## The data model

Deliberately smaller than serde's 29 types. Events:

`null`, `bool`, `i64`, `u64`, `f64`, `str` (UTF-8 `(slice u8)`), `bytes`,
`seq`, `map`, `struct` (named fields, known count), `variant` (externally tagged).

Narrow integer widths (`u8`, `i32`, …) pass through the model as `i64`/`u64`; the
typed struct restores the width on decode, and **decode range-checks and errors**
on overflow (hard-error policy — a `u8` field seeing `300` is a `DeError`, not a
truncation).

## The traits

```coil
(defstruct SerError [(code i64)])                      ; io failure, unsupported, …
(defstruct DeError  [(code i64) (offset i64) (ctx (slice u8))])
; ctx is a static string ("expected number", a field name, …); offset is the
; input byte offset when the backend knows it (the JSON tape does).
```

### Serializer (per format; dyn-safe: every method takes `(s (ptr Self))`)

```coil
(deftrait Serializer [Self]
  (ser-null  [(s (ptr Self))]                    (-> (Result i64 SerError)))
  (ser-bool  [(s (ptr Self)) (v bool)]           (-> (Result i64 SerError)))
  (ser-i64   [(s (ptr Self)) (v i64)]            (-> (Result i64 SerError)))
  (ser-u64   [(s (ptr Self)) (v i64)]            (-> (Result i64 SerError)))  ; bits unsigned
  (ser-f64   [(s (ptr Self)) (v f64)]            (-> (Result i64 SerError)))
  (ser-str   [(s (ptr Self)) (v (slice u8))]     (-> (Result i64 SerError)))
  (ser-bytes [(s (ptr Self)) (v (slice u8))]     (-> (Result i64 SerError)))
  ; containers: begin / per-element / end
  (seq-begin    [(s (ptr Self)) (len i64)]                       (-> (Result i64 SerError)))
  (seq-elem     [(s (ptr Self))]                                 (-> (Result i64 SerError)))
  (seq-end      [(s (ptr Self))]                                 (-> (Result i64 SerError)))
  (map-begin    [(s (ptr Self)) (len i64)]                       (-> (Result i64 SerError)))
  (map-key      [(s (ptr Self)) (k (slice u8))]                  (-> (Result i64 SerError)))
  (map-end      [(s (ptr Self))]                                 (-> (Result i64 SerError)))
  (struct-begin [(s (ptr Self)) (name (slice u8)) (nfields i64)] (-> (Result i64 SerError)))
  (field-key    [(s (ptr Self)) (name (slice u8))]               (-> (Result i64 SerError)))
  (struct-end   [(s (ptr Self))]                                 (-> (Result i64 SerError)))
  ; externally tagged sums; a unit variant is tag-only
  (variant-unit  [(s (ptr Self)) (sum (slice u8)) (tag (slice u8))]               (-> (Result i64 SerError)))
  (variant-begin [(s (ptr Self)) (sum (slice u8)) (tag (slice u8)) (nfields i64)] (-> (Result i64 SerError)))
  (variant-end   [(s (ptr Self))]                                                 (-> (Result i64 SerError))))
```

### Deserializer (per format) — pull, type-directed, not visitor-driven

Serde's visitor exists so a self-describing format can drive shape decisions. We
invert it: the *type* asks for what it expects. Far simpler, no closures needed,
and the JSON token tape makes it cheap — child counts and `object-get` give
random-access field lookup, so **field order never matters** and skipping unknown
fields is a tape-index hop, not a re-parse. The cost is no `serde_json::Value`-style
"deserialize anything" through this trait — that's what the DOM (below) is for.

```coil
(deftrait Deserializer [Self]
  (de-bool [(d (ptr Self))] (-> (Result bool DeError)))
  (de-i64  [(d (ptr Self))] (-> (Result i64 DeError)))
  (de-u64  [(d (ptr Self))] (-> (Result i64 DeError)))
  (de-f64  [(d (ptr Self))] (-> (Result f64 DeError)))
  (de-str  [(d (ptr Self))] (-> (Result (slice u8) DeError)))   ; see Strings & memory
  (de-null? [(d (ptr Self))] (-> bool))                          ; peek — drives Option
  (de-seq-begin [(d (ptr Self))] (-> (Result i64 DeError)))      ; -> element count
  (de-seq-next  [(d (ptr Self))] (-> (Result i64 DeError)))      ; advance to next element
  (de-seq-end   [(d (ptr Self))] (-> (Result i64 DeError)))
  (de-map-begin [(d (ptr Self))] (-> (Result i64 DeError)))      ; -> entry count
  (de-map-key   [(d (ptr Self)) (n i64)] (-> (Result (slice u8) DeError)))
  (de-map-value [(d (ptr Self)) (n i64)] (-> (Result i64 DeError)))  ; position on entry n's value
  (de-map-end   [(d (ptr Self))] (-> (Result i64 DeError)))
  (de-struct-begin [(d (ptr Self)) (name (slice u8))] (-> (Result i64 DeError)))
  (de-field  [(d (ptr Self)) (name (slice u8))] (-> (Result bool DeError)))
  ;   ^ seek to the named field's value; Ok(false) = absent (caller applies default or errors)
  (de-struct-end [(d (ptr Self))] (-> (Result i64 DeError)))
  (de-variant [(d (ptr Self))] (-> (Result (slice u8) DeError))) ; -> the tag; positions on payload
  (de-alloc  [(d (ptr Self))] (-> (ptr alloc/Allocator))))       ; the decode allocator
```

### Serialize / Deserialize (per type — these need NOT be dyn-safe)

```coil
(deftrait Serialize [Self]
  ; ⚠ as-built: BY-VALUE receiver (the show.coil Display pattern) — a struct
  ; param is an immutable ref under the hood, and by-value lets Option/ArrayList
  ; impls recurse on match binders / al-get results directly.
  (ser [(x Self) (s (dyn Serializer))] (-> (Result i64 SerError))))

(deftrait Deserialize [Self]
  ; out-pointer style: fills a caller-owned slot, matching zeroed/store! idiom and
  ; keeping Self out of the return type.
  (de [(out (ptr Self)) (d (dyn Deserializer))] (-> (Result i64 DeError))))
```

⚠ as-built Deserializer deltas: `de-null?` **consumes** the null when it answers
true; there is no `de-seq-next` (formats are count-driven: `de-seq-begin`
returns the element count and each element decode advances); `de-variant-end`
exists and closes the variant frame; `de-bytes` was added alongside `de-str`.

`coil.serde` ships impls for: `i64` (+ narrow widths via specialized impls with
range checks on decode), `bool`, `f64`, `(slice u8)` (as `str`),
`(Option T)` (null ↔ `None`; requires `T : Serialize`/`Deserialize` bounds),
`(ArrayList T)` (seq), `(HashMap (slice u8) V)` (map). All generic impls carry
bounds, e.g. `(impl [(T Serialize)] Serialize (ArrayList T) …)`.

## The derive

`(derive-serde T opts…)` emits both impls for a **struct** (`derive-serialize` /
`derive-deserialize` emit one); `(derive-serde-sum T opts…)` does the same for
an **existing defsum** via the `code-variant-field-name`/`-type` reflection ops
(added to the compiler for exactly this); `(defsum-serde T (V …) … opts…)`
defines the sum and derives in one form. Structs walk `code-field-*`.
(One reflection wart survives on the struct path: `code-field-type` reports a
generic field type as its bare head symbol — `Option`, not `(Option E)` — so
derived code recovers the payload type from the slot via `coil.serde.opt-none!`;
the variant path's new ops return structured, canonically-qualified types.)

The full option set is implemented: `(rename-all :camelCase|:snake_case|:kebab-case)`,
`(deny-unknown)` (opt-in; the default skips unknown input fields), and per-field
`(field NAME (rename "…") (default EXPR) (skip) (skip-serializing)
(skip-deserializing) (with ser-fn de-fn) (boxed))`. Unknown option names are a
hard expansion error. Hook signatures: ser takes the field BY VALUE, de takes
the out-pointer — `[(x FT) (s (dyn Serializer))]` / `[(out (ptr FT)) (d (dyn
Deserializer))]`. `(boxed)` requires a `(ptr T)` field and heap-allocates the
pointee from `de-alloc` on decode (recursive types round-trip).

```coil
(import "coil.serde"        :use *)   ; REQUIRED alongside the derive module
(import "coil.serde.derive" :use *)

(defstruct User [(name (slice u8)) (age u8) (email (slice u8)) (score f64)])
(derive-serde User
  (rename-all :camelCase)
  (field email (rename "emailAddress"))
  (field score (default 0.0)))

(defsum Shape (Circle [(r f64)]) (Rect [(w f64) (h f64)]) (Point))
(derive-serde-sum Shape)               ; post-hoc, via variant-field reflection
; …or define + derive in one form: (defsum-serde Shape (Circle …) … opts…)
; JSON: {"Circle": {"r": 1.5}}   {"Rect": {"w": 2.0, "h": 3.0}}   "Point"
; sexp: (Circle r 1.5)           (Rect w 2.0 h 3.0)               Point
```

Options are ordinary Code arguments — no attribute syntax needed, unknown names
a hard error. Decode semantics: **unknown input fields are skipped** unless
`(deny-unknown)`; **missing fields error** unless the field has `(default …)`
or is an `(Option T)` (absent → `None`).

What derive generates for `User` (sketch of the serialize half):

```coil
(impl Serialize User
  (ser [(x (ptr User)) (s (dyn Serializer))] (-> (Result i64 SerError))
    (try
      (do (try! (struct-begin s "User" 3))
          (try! (field-key s "name"))         (try! (ser (field x name) s))
          (try! (field-key s "emailAddress")) (try! (ser (field x email) s))
          (try! (field-key s "score"))        (try! (ser (field x score) s))
          (struct-end s)))))
```

Nested struct/sum fields recurse **through the trait**, so a hand-written
`(impl Serialize Timestamp …)` on a field's type wins automatically — same
mechanism as `derive-eq` recursing through `=`.

**v1 hard-error list** (per the derive.coil policy — stop, don't guess):
raw `(ptr T)` fields, `(fnptr …)` fields, `(array T N)` / `(vec T N)` fields,
non-`(slice u8)` HashMap keys, sums nested *directly* by value inside another
derived sum's payload if it proves awkward — each with a message naming the field
and the escape hatch: `(field f (with ser-fn de-fn))` substitutes user functions
of the shape `[(x (ptr FT)) (s (dyn Serializer))] (-> (Result i64 SerError))`
(and the `de` mirror) for that field. Phase 2 lifts `(ptr T)` via `(field f
(boxed))` — decode allocates from `de-alloc` and recurses (recursive trees).

## The JSON backend (`coil.serde.json`)

**Serializer** — a struct holding `(ptr Writer)` plus minimal state (depth,
"comma needed" per level, fixed-depth `(array u8 64)` stack; deeper nesting is a
`SerError`, not a corruption). Impls `Serializer`. New code it needs, none of
which exists today:

- string **escaping** on output (`"` `\` control bytes, `\uXXXX` for <0x20);
- `f64` output via libc `snprintf c"%.17g"` — `fmt/print-f` is a fixed 6-digit
  *display* and must not be used for round-tripping (documented in fmt.coil);
- integers via `fmt/print-i` / `print-u` (already correct).

Works with every existing sink: fd, `BufferedWriter`, `FixBuf`. Add a small
`StrBuf`-backed growable `Writer` adapter to `coil.str` for the "to string"
convenience (the one missing sink).

**Deserializer** — a cursor over the existing token tape: `{(doc Doc)
(at i64) …}` plus a small seq/struct index stack. `de-field` is
`json/object-get` from the current container token; `de-seq-begin` reads
`child-count`. New code it needs:

- **number parsing** (tape stores text): strict i64/u64 with overflow → `DeError`,
  and f64 via libc `strtod` on a bounded copy (v1; a hand parser can come later);
- **string unescaping**: the tape keeps encoded bytes (keys compare encoded — a
  known sharp edge of `object-get` this backend hides). Escape-free strings are
  returned as **zero-copy borrows of the input**; strings containing `\` are
  unescaped into `de-alloc` memory. Either way the caller sees a `(slice u8)`.
- `de-field` must compare against *decoded* key bytes (escaped keys in input must
  still match), so the backend wraps `object-get` with unescape-aware compare.

Conveniences:

```coil
;; (from-json [T] a bytes) — parse + decode in one call.
(defn from-json [(T Deserialize)] [(a (ptr alloc/Allocator)) (src (slice u8))]
  (-> (Result T DeError)) …)
;; (to-json x w) — serialize to any Writer; (to-json-str a x) -> (slice u8).
```

**Memory contract** (documented on both): decoded values may **borrow the input
buffer and the decode allocator's memory**. The recommended pattern is an arena
per decode — free the arena, the whole decoded graph dies. Nothing hides an
ownership model that doesn't exist.

## The DOM escape hatch

Promote the example `Json` sum into `coil.serde.json` (or `coil.json.value`) as
the `serde_json::Value` equivalent — `JNull/JBool/JNum/JStr/JArr/JObj` with
`Serialize`/`Deserialize` impls. That covers "shape unknown until runtime"
without complicating the typed pull path, and replaces the ints-only example
with a real one.

## Why not serde's exact shape — decisions and tradeoffs

1. **`dyn` instead of generic trait methods.** Coil trait methods can't take
   their own type params, so `ser` takes `(dyn Serializer)`. Cost: one vtable
   call per data-model event (this is exactly Rust's `erased-serde`, which is the
   proven fallback there). Accepted for v1; the escape is (2).
2. **A fused fast path is a later, pure-library optimization.** Because derive
   sees the whole type tree at expansion time, a format-*specific* derive
   (`derive-json-direct T`) can emit straight `Writer` calls with zero dispatch —
   measure first; add only if the vtable cost shows up.
3. **Pull deserializer instead of visitors.** Type-directed decoding covers the
   defstruct/defsum world without closures; the tape's random access gives
   field-order independence and cheap unknown-field skipping. Dynamic shapes go
   through the DOM.
4. **Externally tagged sums only, in v1.** `{"Tag": {…}}` / `"Tag"` for unit.
   Internal/adjacent tagging and untagged are add-ons to the derive options
   (`(tag "type")`), not new trait surface — the tape's random access makes
   internal tagging feasible later (peek the tag field, then decode).
5. **No `Serialize` for raw pointers.** Addresses don't serialize. `(boxed)` in
   phase 2 for owned recursion is the deliberate, allocator-aware door.

## Phasing

**Done (v1)**: the traits + scalar/slice/Option/ArrayList/HashMap impls; struct
derive; sum derive (`defsum-serde`, externally tagged); JSON both directions
(escaping/unescaping incl. surrogate pairs, strict range-checked numbers,
`%.17g` floats); sexp both directions (own tape reader; carries nan/inf and a
hex bytes literal JSON can't); msgpack both directions (minimal int encodings,
real bytes, strict u64/i64 range rules); the test suite.

**Done (v2)**: the full derive option set (`rename`/`rename-all`/`default`/
`skip`/`skip-serializing`/`skip-deserializing`/`with`/`boxed`/`deny-unknown`,
opt-in); the DOM (`coil.serde.value`'s `JVal` + the `de-kind` peek on
`Deserializer`, implemented by all three backends); per-variant field reflection
in the compiler (`code-variant-field-name`/`-type`, ops 47/48) and post-hoc
`derive-serde-sum` on top of it; `de-struct-begin` now returns the input's
field count (feeds `deny-unknown`). Tests: `tests/serde_options_test.coil`,
`tests/serde_value_test.coil`, `tests/serde_sum_posthoc_test.coil`, and
`tests/metaprogramming/compile-and-run/variantrefl_test.coil` (harness step 9b).

**Remaining**:

1. Alternative sum tagging modes (`(tag "type")`, adjacent, untagged).
2. Promote/retire `src/examples/json.coil` in favor of `JVal`.

## Implementation gotchas (learned on contact)

- **Bind the dyn once.** Auto-coercion `(ptr Backend)` → `(dyn Serializer)`
  works at concrete-impl call sites but not when the receiver dispatches through
  a *generic bounded* impl — so the conveniences (`to-json`, `from-json`, …) do
  `(primitive/make-dyn Serializer s)` once and pass that value. Users of the
  conveniences never see this.
- **Emitted code and type inference.** A standalone `(Err …)`/`(Ok …)` in a
  generated `cond`/`if` arm may not infer its Result type args — the derive
  emits `(Err [i64 DeError] …)` explicitly.
- **Macro-helper calls must keep all-Code args** (plus i64 counters); a helper
  taking a `(slice u8)` param gets treated as surface syntax and mis-expands.
  Comptime strings lift into string-literal Code via `` `~ `` (quasiquote of
  unquote), which is how field-name keys are baked in.
- **`extern` ownership**: `coil.serde` declares `snprintf`/`strtod` once for all
  backends (externs don't dedup across modules); programs using serde must not
  redeclare them.

## Worked examples (proposed surface)

### 1. Basic round-trip

```coil
(module app)
(import "coil.alloc"       :use *)
(import "coil.serde"       :use *)
(import "coil.serde.derive" :use *)
(import "coil.serde.json"  :use *)
(import "coil.io"          :use *)

(defstruct User [(name (slice u8)) (age i64) (email (slice u8))])
(derive-serde User)

(defn main [] (-> i64)
  (let [a (malloc-allocator)
        (mut u) (primitive/zeroed User)]
    (store! (field u name)  "ada")
    (store! (field u age)   36)
    (store! (field u email) "ada@example.com")
    ; -> {"name":"ada","age":36,"email":"ada@example.com"}
    (to-json u (stdout))
    ; and back: parse + typed decode in one call
    (match (from-json [User] a "{\"age\": 36, \"email\": \"ada@example.com\", \"name\": \"ada\"}")
      (Ok  [u2] (do (print-str (stdout) (load (field u2 name))) 0))   ; field order didn't matter
      (Err [e]  1))))
```

### 2. Nesting, Option, ArrayList — all through the same trait

```coil
(defstruct Address [(street (slice u8)) (zip i64)])
(derive-serde Address)

(defstruct Person
  [(name    (slice u8))
   (home    Address)                       ; nested struct: recurses via Serialize
   (nick    (Option (slice u8)))           ; None <-> null / absent field
   (scores  (ArrayList i64))])             ; seq
(derive-serde Person)
; {"name":"jo","home":{"street":"Main St","zip":47374},"nick":null,"scores":[10,20]}
```

### 3. Sums, externally tagged (⚠ as-built: derived at the definition)

```coil
(defsum-serde Shape
  (Circle [(r f64)])
  (Rect   [(w f64) (h f64)])
  (Point))

; (Circle 1.5)  -> {"Circle":{"r":1.5}}
; (Rect 2.0 3.0) -> {"Rect":{"w":2.0,"h":3.0}}
; (Point)        -> "Point"

(defn describe [(src (slice u8)) (a (dyn Allocator))] (-> i64)
  (match (from-json [Shape] a src)
    (Ok [s] (match s
              (Circle [r] 1)
              (Rect [w h] 2)
              (Point [] 3)))
    (Err [_] 0)))
```

### 4. Field options: rename, default, skip

```coil
(defstruct Config
  [(host    (slice u8))
   (port    i64)
   (retries i64)
   (secret  (slice u8))])
(derive-serde Config
  (rename-all :camelCase)                ; maxRetries below is post-rename-all
  (field port    (default 8080))         ; absent on decode -> 8080
  (field retries (rename "maxRetries") (default 3))
  (field secret  (skip)))                ; never written, never read
; {"host":"localhost","port":9000,"maxRetries":3}   (secret omitted)
; decoding {"host":"h"} succeeds: port=8080, retries=3, secret zeroed
```

### 5. Hand-written impl on a field's type (the extensibility hook)

```coil
; Wire format wants epoch seconds, not a struct.
(defstruct Timestamp [(secs i64) (nanos i64)])

(impl Serialize Timestamp
  (ser [(x (ptr Timestamp)) (s (dyn Serializer))] (-> (Result i64 SerError))
    (ser-i64 s (load (field x secs)))))
(impl Deserialize Timestamp
  (de [(out (ptr Timestamp)) (d (dyn Deserializer))] (-> (Result i64 DeError))
    (try (do (store! (field out secs) (try! (de-i64 d)))
             (store! (field out nanos) 0)
             (Ok 0)))))

(defstruct Event [(kind (slice u8)) (at Timestamp)])
(derive-serde Event)          ; derive recurses through the trait, so the
; {"kind":"login","at":1754265600}   hand-written impl wins for `at` — no option needed
```

### 6. Errors, arena-per-decode, and the CLI boundary

```coil
(import "coil.try" :use *)
(import "coil.fmt" :use *)

(defn load-config [(src (slice u8))] (-> i64)
  (let [arena (arena-allocator 65536)]           ; decoded graph borrows src + arena
    (try
      (let [cfg (try-or! (from-json [Config] arena src) 2)]
        ; use cfg... everything it points at lives until the arena dies
        0))))

; a DeError is located: {"port": "yes"} ->
;   (Err {code=EXPECTED-NUMBER offset=9 ctx="port"})
(defn report-de-err [(e DeError)] (-> i64)
  (do (fmt (stderr) "decode error at byte {d}: {s}\n"
        (load (field e offset)) (load (field e ctx)))
      1))
```

### 7. Unknown shape: the DOM

```coil
(import "coil.serde.json" :use *)   ; JVal = the promoted Json sum, itself Serialize/Deserialize

(defn version-of [(a (dyn Allocator)) (src (slice u8))] (-> i64)
  (match (from-json [JVal] a src)          ; any valid JSON decodes
    (Ok [v] (match (jv-get v "version") (JNum [n] n) (_ -1)))
    (Err [_] -1)))
```

### 8. Same derived type, different format — the N+M payoff

```coil
(import "coil.serde.sexp" :use *)
(import "coil.serde.msgpack" :use *)

(to-json u (stdout))          ; {"name":"ada","age":36,...}
(to-sexp u (stdout))          ; (User name "ada" age 36 ...)
(to-msgpack-bytes a u)        ; 0x84 0xa4 name ... (fixmap, minimal encodings)
; one (derive-serde User); the format is picked at the call, not in the type
```

## Open questions

- `de-map-key`/`de-map-value` index-based iteration is O(n²) on the tape for big
  maps (each seek walks from the container start) — fine for v1; a stateful
  entry-cursor variant on the backend can fix it without changing the trait.
- Should `(slice u8)` default to `str` or `bytes` in the model? Proposal: `str`
  (JSON has no bytes); a `(field f (bytes))` option selects base64-as-string
  when a binary format lands.
- Where `u64` lives: the model carries it as `i64` bits with unsigned intent
  (matching `fmt/print-u`); revisit if a real `u64`-typed trait surface proves
  necessary.
