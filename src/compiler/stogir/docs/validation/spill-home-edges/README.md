# Existing-home proof through ordinary CFG edges

The previous uniform and costed home experiments removed contiguous boundary stores but did not apply the same proof to ordinary CFG edge reconciliation. Register-to-home stores therefore remained on provider mismatch paths even after definitions established the homes. Their measured regressions remain valid evidence about those incomplete policies; do not discard that history or claim this correction is faster without timing.

The planner now returns an owned parent-to-home certificate only for complete, compatible, private definitions. The emission view borrows it until the owned transfer plan is released. Both empty-block checks and real lowering use the same view. Ordinary same-parent register-to-exact-home stores are removed before adding Phi moves; register reloads, other destinations, uncertified owners, Phi moves and literals retain existing behavior. Every new/coalesced/Phi definition must still establish its current home. Existing frame/scope/external-entry safeguards remain. No profitability heuristic or allocator-phase change is added.
