## Required proof and integration

1. Derive write effects from exact final emitted bytes with a closed instruction decoder or equally complete emitter effect accounting. Unknown encodings, data, relocations and uncontrolled transfers must decline. Merely collecting register mentions is insufficient.
2. Validate control stays inside the owned body or returns conventionally; no external tail branch or unmodeled helper call. Explicitly account for W-register writes, writeback bases, multiple destinations, SIMD/GP transfers and implicit effects.
3. Bind the certificate to an immutable private body and actual local symbol. Exported/weak/undefined/indirect or unresolved targets retain full ABI clobbers. Never accept a stale summary for a different emitted body.
4. Include caller argument marshalling, hiddenx8 result setup, direct aggregate results, copy machinery, and scratch-register policy. A small callee write mask alone is insufficient.
5. Emit eligible callees once before dependent callers, with deterministic ordering and owned lifetimes. Current Coil emission order is source submission order, so opportunistic order-dependent caching is insufficient.
6. Exercise both AOT and JIT, unknown fallback, multiple callers, body mutation/rebinding rejection, external/indirect calls, argument/result ABI varieties and full native call-clobber tests. Measure actual compiler hot paths before claiming a bootstrap gain.

No production clobber changes, installation, or push in this audit.
